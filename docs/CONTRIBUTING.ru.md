# Как внести свой вклад в проект

Спасибо, что хотите помочь! ❤️

1. Форкните репозиторий.
2. Создайте ветку для вашей правки: `git checkout -b my-change`.
3. Сделайте изменения и закоммитьте их: `git commit -m "Описание изменений"`.
4. Отправьте ветку в ваш форк: `git push origin my-change`.
5. Создайте Pull Request в `polymind`.
6. Перед крупными изменениями обсудите идею: [Open issue](https://github.com/semernyakov/polymind/issues).

Пожалуйста, убедитесь, что код работает и форматирование соблюдено.

## Модель прав по умолчанию

Для внешних соавторов рекомендуемая и стандартная модель участия — форк-воркфлоу.

Это означает:

- соавтор работает в своём собственном форке репозитория
- он пушит только в свой форк
- он открывает Pull Request в основной репозиторий
- он не получает прямой доступ на запись в upstream-репозиторий по умолчанию

Это модель прав, которую мы используем для обычных контрибьюторов. На практике:

- прямой push в основную ветку репозитория не предоставляется
- изменения проходят review до merge
- maintainer сам принимает решение о принятии или отклонении PR

### Стандартный рабочий процесс

```bash
git clone https://github.com/your-user/polymind.git
cd polymind
git checkout -b my-change
git push origin my-change
gh pr create \
  --repo semernyakov/polymind \
  --base polymind \
  --head your-user:my-change \
  --fill
```

Такой подход даёт контрибьютору безопасный путь участия через PR без прямого доступа к основной ветке проекта.

Внося свой вклад, вы соглашаетесь с нашим [Кодексом поведения](./CODE_OF_CONDUCT.ru.md).
