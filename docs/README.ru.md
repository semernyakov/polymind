**PolyMind — это AI-чат для Obsidian, который позволяет использовать ваши заметки непосредственно в качестве контекста для AI-чатов.** Используйте модели от провайдеров Groq и OpenRouter, переключайтесь между моделями в один клик, работайте с `[[wikilinks]]` и управляйте историей диалогов.

PolyMind предназначен для контекстной работы с AI непосредственно внутри Obsidian.

## Контекст заметок

Главная особенность PolyMind — возможность использовать ваш Obsidian Vault в качестве контекста для AI-разговоров.

Вместо того чтобы вручную копировать информацию из заметок в чат, PolyMind может добавлять содержимое заметок непосредственно в контекст разговора.

### Контекст через wikilinks

При включённой настройке `[[wikilinks]]` в вашем сообщении могут быть разрешены до соответствующих заметок, а их содержимое — добавлено в контекст AI.

Например:

```text
Объясни взаимосвязь между [[Project Alpha]] и [[Research Notes]].
```

PolyMind может развернуть связанные заметки и передать их содержимое выбранной AI-модели в качестве контекста.

### Открытые заметки как контекст

PolyMind также позволяет автоматически добавлять все открытые в данный момент заметки в контекст каждого сообщения.

Это удобно при работе с несколькими связанными заметками, исследовательскими материалами, проектами или документацией.

### Ограничения контекста

Чтобы контролировать объём информации, отправляемой AI-провайдеру, PolyMind позволяет задать максимальное количество символов для каждой заметки.

Можно установить:

* определённое количество символов для ограничения размера контекста;
* `0`, чтобы включать заметку целиком.

## AI-провайдеры

PolyMind поддерживает AI-модели через несколько провайдеров.

### Groq

Groq предоставляет доступ к быстрому AI-инференсу и динамически обновляемому каталогу моделей.

### OpenRouter

OpenRouter предоставляет доступ к моделям различных AI-провайдеров через единый API.

Доступные модели зависят от текущего каталога провайдера и настроек вашего провайдера.

> Доступность моделей зависит от провайдера и может меняться со временем. PolyMind не поддерживает статический список доступных моделей.

## Управление моделями

PolyMind не содержит фиксированного вручную поддерживаемого списка моделей.

Вместо этого плагин запрашивает актуальный каталог моделей у настроенного провайдера и обновляет доступные модели при необходимости.

Это означает:

* новые модели могут появляться без выпуска новой версии PolyMind;
* модели могут стать недоступными или быть удалены провайдером;
* информация о моделях может меняться со временем;
* список моделей в PolyMind отражает текущий каталог провайдера;
* разные провайдеры могут предоставлять разные модели и возможности.

### Обновление списка моделей

Чтобы обновить список моделей:

1. Откройте **Настройки Obsidian**.
2. Откройте настройки **PolyMind**.
3. Найдите раздел настройки моделей.
4. Нажмите кнопку обновления рядом с выбором модели.
5. PolyMind загрузит актуальный каталог моделей у провайдера.
6. Выберите модели, которые хотите использовать.

Для удобства навигации по большим каталогам модели могут группироваться по провайдеру или владельцу.

## Статус проекта

PolyMind активно развивается и ориентирован на контекстные AI-разговоры внутри Obsidian.

Текущая версия поддерживает:

* AI-чат с Groq;
* AI-чат с OpenRouter;
* динамическое получение списка моделей;
* переключение между моделями в один клик;
* использование содержимого заметок в качестве контекста AI;
* разворачивание `[[wikilinks]]`;
* использование открытых заметок в качестве контекста;
* сохранение истории разговоров;
* отображение Markdown и кода;
* создание заметок из ответов AI;
* работу на компьютерах и мобильных устройствах.

### Мультимодальные возможности

Текущие сценарии работы PolyMind в первую очередь ориентированы на текст и код.

Хотя некоторые провайдеры могут предоставлять модели с поддержкой изображений, аудио или других мультимодальных возможностей, PolyMind пока не гарантирует поддержку всех возможностей таких моделей.

Поэтому каталог моделей провайдера фильтруется в соответствии с возможностями, которые в данный момент поддерживает плагин.

Дополнительные мультимодальные возможности могут появиться в будущих версиях.

## Установка

### Community Plugins

1. Откройте **Настройки Obsidian**.
2. Перейдите в раздел **Community plugins**.
3. Убедитесь, что Community plugins включены.
4. Нажмите **Browse**.
5. Найдите **PolyMind**.
6. Установите плагин.
7. Включите PolyMind.

## Настройка

После установки PolyMind:

1. Откройте **Настройки Obsidian**.
2. Откройте настройки **PolyMind**.
3. Настройте AI-провайдера.
4. Введите необходимый API-ключ.
5. Выберите модели, которые хотите использовать.
6. Настройте параметры чата, контекста заметок и истории.

### API-ключи

Для Groq получите API-ключ в [Groq Console](https://console.groq.com).

Для OpenRouter получите API-ключ на [OpenRouter](https://openrouter.ai/).

API-ключи хранятся локально в вашей среде Obsidian и используются для связи с настроенным провайдером.

### Настройки контекста заметок

Настройки **Note context** определяют, как заметки Obsidian добавляются в AI-разговоры.

Доступны следующие параметры:

* **Open chat on startup** — автоматически открывать чат PolyMind при запуске Obsidian.
* **Expand `[[links]]` in your message** — разрешать wikilinks в сообщении и добавлять содержимое соответствующих заметок в контекст.
* **Include all open notes as context** — добавлять все открытые заметки в контекст каждого сообщения.
* **Max characters per note** — ограничивать количество содержимого каждой заметки. Значение `0` означает включение заметки целиком.

## Использование

1. Откройте заметку в Obsidian.
2. Откройте PolyMind через боковую панель.
3. Выберите AI-провайдера и модель.
4. Начните разговор.
5. Добавьте необходимые заметки в контекст разговора с помощью wikilinks или контекста открытых заметок.
6. Продолжайте работать со своим Vault, не покидая Obsidian.

### Пример

Предположим, ваш Vault содержит:

```text
Projects/
├── Project Alpha.md
├── Project Beta.md
└── Meeting Notes.md
```

Вы можете спросить:

```text
Сравни [[Project Alpha]] и [[Project Beta]]
на основе последней версии [[Meeting Notes]].
```

При включённом контексте заметок PolyMind сможет использовать содержимое этих заметок при формировании ответа.

## История чатов

PolyMind поддерживает сохранение истории разговоров с использованием нескольких вариантов хранения.

Доступные варианты:

* Хранение в памяти;
* `localStorage`;
* IndexedDB;
* хранение в файлах.

Можно настроить:

* способ хранения истории;
* максимальную длину истории;
* объём истории, загружаемый при открытии разговора.

Подходящий вариант хранения зависит от вашего рабочего процесса и объёма истории разговоров, которую вы хотите сохранять.

## Режимы отображения

PolyMind может отображаться в разных вариантах интерфейса Obsidian.

В зависимости от настроек чат может открываться:

* в отдельной вкладке;
* в боковой панели.

Также можно настроить автоматическое открытие чата при запуске Obsidian.

## Тестирование плагина с помощью BRAT

Вы можете установить и протестировать последнюю версию PolyMind из ветки разработки с помощью [BRAT](https://github.com/TfTHacker/obsidian42-brat) — инструмента для тестирования бета-плагинов Obsidian.

### Шаги

1. Установите BRAT из Community Plugins Obsidian.
2. Откройте настройки BRAT.
3. Нажмите **Add Beta Plugin**.
4. Укажите URL репозитория:

```text
https://github.com/semernyakov/polymind
```

5. Подтвердите установку.

BRAT установит версию PolyMind из репозитория разработки и сможет автоматически обновлять её при появлении новых версий.

## Разработка

Клонируйте репозиторий:

```bash
git clone https://github.com/semernyakov/polymind.git
cd polymind
```

Установите зависимости:

```bash
npm install
```

Запустите сборку в режиме разработки:

```bash
npm run dev
```

Соберите плагин:

```bash
npm run build
```

Форматируйте код:

```bash
npm run format
```

Запустите проверку линтера:

```bash
npm run lint
```
